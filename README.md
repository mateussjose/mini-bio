## 💻 Projeto

O aplicativo apresenta um perfil pessoal por meio de uma interface minimalista, com tema escuro e detalhes em azul. O conteúdo é organizado em uma única tela, destacando a fotografia, o nome completo, a formação acadêmica e uma breve biografia.

## 🚀 Tecnologias

O projeto foi desenvolvido utilizando:

- **React Native** — Desenvolvimento da interface mobile.
- **Expo** — Plataforma de desenvolvimento e execução.
- **Expo Router** — Gerenciamento da estrutura de navegação.
- **JavaScript / TypeScript** — Linguagens utilizadas no ecossistema do projeto.
- **EAS Update** — Publicação de atualizações Over-the-Air.
- **Git e GitHub** — Versionamento e hospedagem do código-fonte.

## ⚙️ Funcionalidades

- Exibição de fotografia pessoal.
- Nome completo em destaque.
- Apresentação da formação acadêmica.
- Mini biografia pessoal.
- Interface responsiva e minimalista.
- Compatibilidade com Android e iOS.
- Publicação de atualizações via Expo.

## 📱 Execução

### Pré-requisitos

- Node.js
- npm
- Expo Go (para execução compatível no dispositivo móvel)

### Instalação

Clone o repositório:

```bash
git clone https://github.com/mateussjose/mini-bio.git
```

Acesse o diretório:

```bash
cd mini-bio
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npx expo start
```

Para visualizar no navegador, pressione `W` no terminal.

Para executar no celular, utilize o Expo Go, desde que a versão do projeto seja compatível.
